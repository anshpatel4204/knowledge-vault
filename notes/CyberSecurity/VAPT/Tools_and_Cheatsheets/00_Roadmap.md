## How to Use This Folder

Unlike the other VAPT folders, Tools_and_Cheatsheets isn't a conceptual learning sequence — it's a living reference. The two notes below inventory the core software toolkit used across the whole VAPT track: what each tool does, which specialization folder it belongs to, and where to actually learn it. Read them once end-to-end to get the map, then come back to individual entries as reference whenever a technique note in another folder mentions a tool by name.

**Currently available:**

1. [[Software_Toolkit_Part1_Recon_Network_Passwords]] — reconnaissance, network scanning/enumeration, and password/credential attack tools
2. [[Software_Toolkit_Part2_Exploitation_Web_AD_Wireless]] — exploitation frameworks, web application testing, Active Directory, and wireless/mobile/cloud tools

**Planned (not yet written):** per-tool deep-dive cheatsheets (Nmap, Metasploit, Burp Suite, etc.) with actual command syntax and flags — the two notes above are the "what and why," these future ones will be the "exact commands."
