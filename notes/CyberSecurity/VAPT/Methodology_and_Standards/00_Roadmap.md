## How to Use This Folder

This roadmap gives the recommended reading order for Methodology_and_Standards — from the industry frameworks that define how testing should be structured, through the practical documents (scoping, Rules of Engagement) that make an engagement legal, to the attacker-behavior model that ties methodology to real-world tradecraft.

**Start here:** [[PTES_Overview]]
**Finish here:** [[MITRE_ATTACK_for_Pentesters]]

## Stage 1 — Industry Standards

The major published frameworks — know what each one is for before picking one for an engagement.

1. [[PTES_Overview]] — the Penetration Testing Execution Standard's seven phases
2. [[OSSTMM_Overview]] — the Open Source Security Testing Methodology Manual, metrics-driven testing
3. [[OWASP_Testing_Guide]] — the web-focused testing standard (bridges directly into Folder 4, Web_Application_Pentesting)
4. [[NIST_SP_800-115]] — the US government's technical testing guideline

## Stage 2 — Running a Real Engagement

The practical documents and decisions that turn a standard into an actual, authorized job.

5. [[Types_of_Pentest_Black_Grey_White_Box]] — how much knowledge the tester starts with
6. [[Scoping_and_Rules_of_Engagement]] — defining what's authorized, in writing, before anything starts
7. [[VAPT_Engagement_Lifecycle]] — pre-engagement through retest, end to end
8. [[Legal_and_Ethical_Considerations]] — the line between authorized testing and a crime

## Stage 3 — Attacker Behavior Model (Capstone)

9. [[MITRE_ATTACK_for_Pentesters]] — mapping engagement activity to real-world adversary tactics and techniques
