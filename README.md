# Knowledge Vault

A personal knowledge base for notes, references, and resources — organized for easy search and reuse.

## Contents

- `notes/` — raw notes and ideas
- `resources/` — links, articles, and references
- `templates/` — reusable note templates

## Usage

Clone the repo and add notes as Markdown files. Organize by topic using folders or tags.

```bash
git clone https://github.com/<your-username>/knowledge-vault.git
```
