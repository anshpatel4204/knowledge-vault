# 📚 Knowledge Vault

> A personal, structured knowledge base covering CyberSecurity, Programming, Systems, Databases, Cloud, DevOps, AI/ML, and more.
> Built and maintained in [Obsidian](https://obsidian.md) by **Ansh Patel**.

---

## 🧭 About

This vault is where I collect, organize, and revise everything I learn — lecture notes, self-study, lab work, and interview prep — in one searchable, cross-linked place instead of scattered files. It's a living document: expect gaps, checkboxes, and half-finished sections. That's the point — it grows as I do.

---

## 🗂 Vault Structure

```
knowledge-vault/
│
├── README.md          ← You are here
├── INDEX.md            ← Master index of every topic in the vault
├── ROADMAP.md          ← What to study next, and in what order
├── CHANGELOG.md        ← Log of what was added or changed
├── TODO.md             ← Topics queued up but not written yet
│
├── notes/
│   ├── CyberSecurity/       Fundamentals, Networking, Web Security, Cryptography, VAPT, DF, SOC
│   ├── Programming/         C, C++, Python, and more
│   ├── Operating Systems/   Linux, Windows, processes, threads
│   ├── Databases/           SQL, NoSQL, design
│   ├── AI-ML/                Machine learning, deep learning, LLMs, prompt engineering
│   ├── Cloud/                AWS, Azure, GCP
│   ├── DevOps/               CI/CD, containers, IaC
│   ├── Web Development/      Frontend, backend, APIs
│   ├── Mathematics/          Discrete math, linear algebra, statistics
│   ├── MCA/                  Coursework notes by semester
│   ├── Career/                Resume, interview prep, certifications
│   └── Projects/              Personal and academic project docs
│
├── templates/          Reusable note templates
├── resources/           External links, cheat sheets, references
└── assets/              Images and attachments used in notes
```

## ✍️ How Notes Are Organized

- Every subject lives under `notes/<Domain>/`, broken into topic subfolders as it grows.
- Checkboxes (`- [ ]`) in [[INDEX]] and [[TODO]] track what's written vs. still queued.
- Notes cross-link using `[[wikilinks]]` so related topics stay connected.
- `templates/` holds reusable note skeletons so new notes start consistent.
